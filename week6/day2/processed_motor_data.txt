WEEK 6 – DAY 2
CREATING THE FAILURE-SOON TARGET

The original AI4I dataset contains a Machine failure target indicating
whether failure is associated with the current record. For predictive
maintenance, a new Failure_Soon target was created to indicate whether
a failure occurs within the next five records in UDI order.

Target definition:

Failure_Soon = 0 → No failure occurs within the next five records.
Failure_Soon = 1 → At least one failure occurs within the next five
records.

The last five records were removed because a complete future window was
not available.

Results:
Original records: 10,000
Processed records: 9,995
Failure_Soon = 1: 1,435
Failure_Soon = 0: 8,560
Failure_Soon rate: 14.36%

Example:
UDI 46 is labeled Failure_Soon = 1 because UDI 51, one of its next
five records, has Machine failure = 1.

UDI 51 is labeled Failure_Soon = 0 because none of UDI 52–56 has
Machine failure = 1.

Important limitation:
The AI4I dataset does not provide timestamped longitudinal measurements
for individual motors. Therefore, the five-record window is a simplified
UDI-order proxy for learning and does not represent an actual future
time interval or confirmed pre-failure sequence.
