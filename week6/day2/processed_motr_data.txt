WEEK 6 – DAY 2
CREATING A FAILURE-SOON PREDICTION TARGET

The original AI4I dataset contained 10,000 records. A five-record future
window was defined for this learning exercise. For each record, the next
five records in UDI order were checked for a Machine failure event.

If a failure occurred within the next five records, Failure_Soon was set
to 1. Otherwise, it was set to 0.

After removing the final five records, which do not have a complete future
window, the processed dataset contained 9,995 records.

Failure_Soon = 1: 1,435 records
Failure_Soon = 0: 8,560 records
Failure_Soon rate: 14.36%

Example:
UDI 46 was assigned Failure_Soon = 1 because UDI 51, one of the next five
records, contains a machine failure.

UDI 51 was assigned Failure_Soon = 0 because its next five records
(52–56) contain no failure.

Important limitation:
The AI4I dataset does not provide timestamped longitudinal observations
for individual motors. Therefore, the five-record window is a simplified
UDI-order proxy and must not be interpreted as a real five-time-unit
prediction horizon.
