Questions

1. What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence that enables computer systems to learn patterns from data and use those learned patterns to make predictions or decisions without being explicitly programmed with rules for every situation.

2. What is a feature? What is a label?

A feature is an input variable used by a Machine Learning model to learn patterns and make predictions. A label is the known target/output that the model learns to predict in supervised learning.

3. Why did we split our dataset into training and testing data?

We split the dataset so that the model can learn patterns from the training data and then be evaluated using previously unseen testing data. This helps determine whether the model can generalize its learned patterns to new data rather than simply memorizing the training examples.

4. What does fit() do? What does predict() do?

fit() trains the model by allowing it to learn patterns from the training features and their known labels.

predict() uses the patterns learned during training to make predictions for new or unseen data.

5. Your model has 95% accuracy. Does that mean it is perfect?

No. A 95% accuracy score means that 95% of the evaluated predictions were correct, but it does not mean that the model is perfect. Accuracy can be misleading, especially when the classes are imbalanced. Therefore, other metrics such as precision, recall, F1-score, and the confusion matrix should also be considered when evaluating a Machine Learning model.
