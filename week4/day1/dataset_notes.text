DAY 1 – MOTOR DATASET EXPLORATION

Dataset:
AI4I 2020 Predictive Maintenance Dataset

Dataset Size:
10,000 records and 14 columns.

Dataset Purpose:
The dataset is designed for predictive-maintenance and machine-failure
prediction exercises.

COLUMN UNDERSTANDING

1. UDI
Unique identifier for each data record.

2. Product ID
Identifier for the individual product.

3. Type
Product quality/variant type: L, M or H.

4. Air temperature [K]
Temperature of the surrounding air in Kelvin.

5. Process temperature [K]
Temperature of the machine/process in Kelvin.

6. Rotational speed [rpm]
Speed at which the machine rotates, measured in revolutions per minute.

7. Torque [Nm]
Rotational force produced by the machine.

8. Tool wear [min]
Amount of tool wear accumulated during operation.

9. Machine failure
Overall failure label indicating whether a machine failure occurred.
0 = No failure
1 = Failure

10. TWF
Tool Wear Failure indicator.

11. HDF
Heat Dissipation Failure indicator.

12. PWF
Power Failure indicator.

13. OSF
Overstrain Failure indicator.

14. RNF
Random Failure indicator.

Potential Features for Predicting Machine Failure:
- Type
- Air temperature [K]
- Process temperature [K]
- Rotational speed [rpm]
- Torque [Nm]
- Tool wear [min]

Target:
- Machine failure

Notes:
UDI and Product ID are identifiers rather than physical operating
measurements and are not considered useful predictive features for
the initial model.

TWF, HDF, PWF, OSF and RNF describe specific failure modes and should
not be used as ordinary input features when predicting Machine failure,
because they contain information directly related to the failure outcome.
