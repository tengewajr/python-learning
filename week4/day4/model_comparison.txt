INTERPRETATION
------------------------------------------------------------
Random Forest achieved slightly higher accuracy (98.10%) and
much higher precision (89.47%) than the Decision Tree (97.85%
accuracy, 68.66% precision). However, Random Forest recall was
only 50.00%, meaning it detected 34 of the 68 actual failure
cases and missed 34 failures.

Decision Tree achieved higher recall (67.65%) and higher F1-score
(68.15%) than Random Forest (50.00% recall, 64.15% F1-score).
It correctly detected 46 of the 68 actual failure cases and
missed 22 failures.

For a predictive-maintenance fault-detection task, missing a real
failure (false negative) can be more concerning than generating
a false alarm (false positive). Therefore, based on the current
results and the goal of detecting motor failures, the Decision
Tree is selected as the better model for Version 1.

Important:
Feature importance shows which features the Random Forest found
useful for making predictions. It does not prove that a feature
causes motor failure. Also, the AI4I dataset is synthetic, so
these results should not be treated as proof of real industrial
deployment performance.

Recommended model for Day 5:
Decision Tree Classifier, because it provides better recall and
F1-score for the current failure-detection objective.
